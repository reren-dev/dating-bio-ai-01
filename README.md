## The line

> I don't sleep, I don't eat, and I've already read your search history — but go on, tell me about yourself like I don't already know how this ends.

## How it works

`main.py` (Python 3.13, standard library only, no network, no wall clock)
writes that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Two runs are
byte-identical.

## Run it

```sh
python3 main.py
```
